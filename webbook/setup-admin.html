관리자 기능 연결

관리자 비밀번호의 검증값은 기존 비공개 구글 시트에 설정했습니다. 아래 코드에는 비밀번호가 포함되어 있지 않습니다.

1. 수정 코드 전체 복사

코드를 불러오고 있습니다.

2. 기존 프로젝트에 붙여 넣기

  1. Google Apps Script에서 기존 질문예술학교 웹북 프로젝트를 엽니다.
  2. Code.gs 내용을 복사한 전체 코드로 교체하고 저장합니다.
  3. 새 프로젝트를 만들거나 setup을 다시 실행할 필요는 없습니다. 기존 스크립트 속성은 그대로 유지합니다.

3. 기존 웹 앱을 새 버전으로 배포

배포 → 배포 관리 → 기존 웹 앱 선택 → 연필 → 새 버전 → 배포

실행 사용자는 ‘나’, 액세스 권한은 ‘모든 사용자’를 유지합니다. 관리자 소감 조회는 서버의 비밀번호·로그인 검증을 통과해야만 가능합니다. 기존 PDF 신청·소감·방문 집계도 함께 유지됩니다.
