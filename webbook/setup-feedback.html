소감 기능 연결

기존 PDF 신청 기능을 유지하면서 공개·비공개 소감을 추가합니다. 새 프로젝트를 만들 필요는 없습니다.

1. 코드 전체 복사

코드를 불러오고 있습니다.

2. 기존 Apps Script에 붙여 넣기

  1. Google Apps Script 열기 ↗에서 질문예술학교 웹북 프로젝트를 선택합니다.
  2. Code.gs 내용을 모두 지우고 복사한 코드를 붙여 넣은 뒤 저장합니다.
  3. 위쪽 함수 목록에서 setup을 골라 한 번 실행합니다. 기존 PDF 신청 정보는 그대로 두고 웹북 소감 탭을 추가합니다.

3. 기존 웹 앱을 새 버전으로 배포

  1. 배포 → 배포 관리를 누릅니다.
  2. 기존 웹 앱을 선택한 뒤 연필 모양 → 버전 ‘새 버전’ → 배포를 누릅니다.
  3. 실행 사용자는 나, 액세스 권한은 모든 사용자를 유지합니다. 기존 배포를 수정하면 주소도 유지됩니다.

공개는 기본 선택이며, 비공개 글은 관리자 구글 시트에서만 볼 수 있습니다. 연결 전에는 웹북에 작동하지 않는 입력창을 표시하지 않습니다.
