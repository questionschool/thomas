방문자 집계 연결

낭만북클럽과 같은 자체 집계 방식입니다. 기존 PDF 신청·소감 기능을 유지하며 누적·오늘 방문 수와 PDF 다운로드 수를 추가합니다. 새 프로젝트를 만들 필요는 없습니다.

날짜 형식 오류 수정본: 구글 시트가 방문일을 날짜형으로 변환해도 오늘 방문과 중복 방지가 정상 작동하도록 수정했습니다. 아래 전체 코드로 교체하고 기존 배포를 새 버전으로 갱신해 주세요.

1. 코드 전체 복사

코드를 불러오고 있습니다.

2. 기존 Apps Script에 붙여 넣기

  1. Google Apps Script 열기 ↗에서 질문예술학교 웹북 프로젝트를 선택합니다.
  2. Code.gs 내용을 모두 지우고 복사한 코드를 붙여 넣은 뒤 저장합니다.
  3. 기존 프로젝트와 스크립트 속성은 그대로 유지합니다. 별도의 setup 실행은 필요 없으며, 첫 방문 때 웹북 방문 통계 탭이 만들어집니다.

3. 기존 웹 앱을 새 버전으로 배포

  1. 배포 → 배포 관리를 누릅니다.
  2. 기존 웹 앱을 선택한 뒤 연필 모양 → 버전 ‘새 버전’ → 배포를 누릅니다.
  3. 실행 사용자는 나, 액세스 권한은 모든 사용자를 유지합니다. 기존 배포를 수정하면 주소도 유지됩니다.

같은 브라우저는 한국 시간 기준 하루 한 번 집계합니다. 실제 집계와 별도로 표시 시작값(누적 1,000·일일 100·PDF 100)을 더합니다. 2026년 11월 7일의 일일 표시값에는 35를 한 번 더합니다. 누적 수는 일일 방문 수의 합계입니다. PDF 다운로드는 신청 완료 건수를 세며 설정 확인용 신청은 제외합니다. 기존 신청·소감 정보와 연결하지 않으며, 집계 서버 연결 전에는 숫자를 표시하지 않습니다.
